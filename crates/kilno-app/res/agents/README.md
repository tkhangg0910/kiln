Agent marks drawn in place of the "CC" / "CX" tags (`src/agent_logo.rs`).

- `claude.png`: Claude's mark, from Simple Icons 13.21.0 `icons/claude.svg`.
- `codex.png`: OpenAI's mark (Codex has none of its own there), from Simple Icons 13.21.0 `icons/openai.svg`.

Each SVG path was filled white and rendered at 128 x 128 on a transparent background with
headless Edge (`--default-background-color=00000000 --window-size=128,128 --screenshot`).
The SVG paths are CC0 (Simple Icons); the marks are trademarks of Anthropic and OpenAI, used
only to say which agent a session runs.
